## 🚀 1. Producto vs Servicio

| Atributo | Producto | Servicio |
|---|---|---|
| **Naturaleza** | Tangible | Intangible |
| **Forma de acceso** | Adquisición | Involucramiento |
| **Almacenamiento** | Almacenable | No almacenable |
| **Relación base** | Necesidad | Confianza |

## 📈 2. Ciclo de Vida del Producto

- 🧭 **Lectura general:** un producto pasa por introducción, crecimiento, madurez y declive.

| Etapa | Actividades clave |
|---|---|
| **Introducción** | Ideación, validación, planeamiento, construcción, lanzamiento (`MVP`) |
| **Crecimiento** | Retención de clientes, expansión de marca, aumento de calidad |
| **Madurez** | Mejora de `ROI` y `CAC`, mayor fidelidad |
| **Declive** | Caída de ventas, evaluar nuevos lanzamientos |

| Introducción: sub-etapa | Disciplina asociada |
|---|---|
| **Ideación + validación** | `Design Thinking` |
| **Planeamiento** | Planeamiento estratégico |
| **Construcción** | Ciclo de vida de desarrollo de software |
| **Lanzamiento** | Go to market |

## 🧠 3. Pensamiento de Diseño

- ⚠️ **Fallo principal al diseñar:** construir algo que nadie quiere o usa.
- 👥 **Centrado en lo humano:** comprender necesidades y motivaciones reales.
- 🧪 **Experimental:** habilita probar, fallar y aprender rápido.

| Etapa | Modo de pensamiento | Resultado |
|---|---|---|
| **Empatizar** | Convergente | Entender personas y contexto |
| **Definir** | Convergente | Problema concreto e insights |
| **Idear** | Divergente | Opciones de mejora |
| **Prototipar** | Convergente | Soluciones tangibles |
| **Evaluar** | Convergente | Validación e iteración |

## 🧰 4. Herramientas por Etapa

| Etapa | Herramientas sugeridas |
|---|---|
| **Empatizar** | Mapa de actores, observación encubierta, mapa de empatía |
| **Definir** | Mapa de causa raíz, inmersión cognitiva |
| **Idear** | `Brainstorming`, entrevistas |
| **Prototipar** | Mapa mental, storyboard, diseño de prototipos |
| **Evaluar** | Elevator pitch, presentación de prototipo |
