## 🚀 1. Proyectos

- 🎯 **Definición:** conjunto de actividades planificadas para lograr un objetivo en tiempo definido.
- 🧠 **Objetivo bien redactado:** formato `SMART`.

| Componente | Qué define | Ejemplo |
|---|---|---|
| **Objetivo** | Resultado a lograr | Aumentar conversión 20% en 30 días |
| **Alcance** | Qué incluye / excluye | Incluye checkout, excluye logística |
| **Restricciones** | Límites de costo, tiempo y recursos | Presupuesto fijo + fecha límite |
| **Recursos** | Medios para ejecutar | Equipo, tecnología, materiales |

| Fase | Enfoque |
|---|---|
| **Iniciación** | Definir alcance, objetivos y autorización |
| **Planificación** | Cronograma, presupuesto, recursos y riesgos |
| **Ejecución** | Implementar, coordinar y asegurar calidad |
| **Monitoreo y control** | Comparar avance y corregir desvíos |
| **Cierre** | Entrega final y lecciones aprendidas |

## ⚙️ 2. Procesos

- 🔁 **Definición:** secuencia de pasos para lograr un resultado.
- 🧭 **Importancia:** ordena el trabajo, reduce caos y baja retrabajo.

| Tipo de proceso | Ejemplos | Valor que aporta |
|---|---|---|
| **Gestión de proyectos** | `Scrum`, `PMBOK` | Organización, prioridades y seguimiento |
| **Técnico** | `Agile`, `Waterfall` | Forma de construir y validar |

| Beneficio | Impacto práctico |
|---|---|
| **Organización y eficiencia** | Menos errores por improvisación |
| **Gestión de riesgos** | Problemas detectados antes |
| **Adaptación al cambio** | Ajustes más rápidos ante nuevos requisitos |

## 📦 3. Productos

- 🏁 **Definición:** resultado tangible del trabajo (`software`, `sistema`, `app`).

| Característica | Qué implica |
|---|---|
| **Funcionalidad** | Cumplir necesidades y requerimientos |
| **Calidad** | Confiabilidad, rendimiento y seguridad |
| **Mantenibilidad** | Facilidad para corregir y evolucionar |

| Ciclo de vida del producto | Actividad principal |
|---|---|
| **Concepción** | Identificar necesidad y definir producto |
| **Desarrollo** | Diseñar, construir y probar |
| **Implementación** | Entregar y poner en marcha |
| **Mantenimiento** | Soporte, mejoras y correcciones |
| **Retirada** | Discontinuar o reemplazar |

## 👥 4. Personas

- 🔑 **Idea clave:** son el recurso más crítico del proyecto.

| Rol | Responsabilidad |
|---|---|
| **Desarrolladores** | Implementar funcionalidades y resolver lo técnico |
| **Analistas** | Capturar y documentar requisitos |
| **Testers** | Verificar calidad y detectar fallos |
| **Gestores de proyecto** | Coordinar recursos, tiempos y comunicación |

| Factor humano | Efecto directo |
|---|---|
| **Competencia + colaboración** | Mayor probabilidad de éxito |
| **Cultura organizacional** | Impacto en moral y productividad |

## 📊 5. Indicadores y Restricciones

| Concepto | Definición breve | Uso práctico |
|---|---|---|
| **Triple restricción** | `Costo`, `Alcance`, `Tiempo` | Balancear decisiones de proyecto |
| **KPI** | `Key Performance Indicator` | Medir avance y desempeño |
| **SLA** | `Service Level Agreement` | Acordar nivel de servicio esperado |

| Ejemplo SMART | Fórmula |
|---|---|
| Objetivo comercial | “Vender 100 unidades por mes en 90 días” |
| Mejora de conversión | “Aumentar ratio 20% en 30 días” |
| Reducción de costos | “Reducir costo 10% en 30 días” |

## 🧩 6. Conceptos Complementarios

| Tema | Resumen |
|---|---|
| **Ciclo iterativo incremental** | Entregar valor en partes y aprender en cada iteración |
| **MVP** | `Minimum Viable Product`: versión mínima útil para validar hipótesis |
| **Ciclo de vida de software** | Planificación, análisis, diseño, codificación, pruebas, implementación y mantenimiento |
| **Tipos de sistemas** | Abiertos, cerrados y aislados (según intercambio con el entorno) |
