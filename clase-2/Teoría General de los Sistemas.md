## 🚀 1. Origen y Enfoque

- 👨‍🔬 **Base teórica:** desarrollada por **Ludwig von Bertalanffy** (1920-1950).
- 🌐 **Objetivo:** identificar principios comunes entre sistemas de distintas disciplinas.
- 🔭 **Visión holística:** entender el sistema como un todo integrado.

## 🧩 2. Concepto de Sistema

- 🎯 **Definición:** conjunto de elementos interrelacionados con objetivo común.
- 🔁 **Interdependencia:** cambios en una parte impactan el comportamiento total.

| Ejemplos de sistema | Tipo de ejemplo |
|---|---|
| Ecosistema | Natural |
| Organización | Social |
| Programa informático | Artificial |
| Tren de carga / cuerpo humano | Técnico / biológico |

## 🏗️ 3. Atributos del Sistema

| Atributo | Qué representa |
|---|---|
| **Elementos** | Componentes que lo conforman |
| **Relaciones** | Vínculos no azarosos entre elementos |
| **Objetivo** | Propósito común (`teleología`) |
| **Límite** | Frontera con su entorno |

## 🌍 4. Comportamiento y Entorno

- 🚧 **Frontera:** define qué pertenece al sistema y qué queda afuera.
- 🌦️ **Ambiente:** condiciones externas que influyen en su desempeño.

| Tipo de sistema | Intercambio con entorno | Rasgo |
|---|---|---|
| **Abierto** | Materia y energía | Adaptable |
| **Cerrado** | Solo energía | Menor intercambio |
| **Aislado** | Nada | Sin intercambio |

## 🗂️ 5. Clasificaciones de Sistemas

| Criterio | Categorías | Ejemplo |
|---|---|---|
| **Propósito** | Naturales / Artificiales | Ecosistema / sistema de información |
| **Composición** | Concretos / Abstractos | Computadora / modelo matemático |
| **Cambio temporal** | Estáticos / Dinámicos | Estructura fija / mercado |
| **Complejidad** | Simples / Complejos | Regla simple / red urbana |

## ⚙️ 6. Cualidades Clave

| Cualidad | Definición aplicada |
|---|---|
| **Entropía** | Tendencia al desorden |
| **Homeostasis** | Equilibrio interno |
| **Sinergia** | El todo supera la suma de partes |
| **Feedback positivo** | Amplifica cambios |
| **Feedback negativo** | Estabiliza |
| **Equifinalidad** | Mismo resultado por caminos distintos |
| **Permeabilidad** | Grado de intercambio con entorno |
| **Adaptabilidad** | Ajuste ante cambios externos |
| **Emergencia** | Surgen propiedades nuevas del conjunto |

## 🔢 7. Dato e Información

| Concepto | Definición | Nota clave |
|---|---|---|
| **Dato** | Representación simbólica sin contexto propio | Puede ser numérico, textual, visual |
| **Información** | Datos organizados con sentido y utilidad | Reduce incertidumbre y apoya decisiones |

| Tipo de dato | Ejemplo |
|---|---|
| **Cuantitativo** | `25 años`, `80 kg` |
| **Cualitativo** | `Buenos Aires`, `color rojo` |

- 🧠 **Idea práctica:** el valor de un dato depende del contexto (por ejemplo, `10` puede significar cosas distintas).

| Requisito de información eficiente | Ejemplo rápido |
|---|---|
| **Exactitud** | Balance contable correcto |
| **Relevancia** | Dato útil para el objetivo |
| **Oportunidad** | Alerta antes del evento |
| **Integridad** | Información completa |
| **Claridad** | Fácil de entender |
| **Consistencia** | Misma cifra en distintos reportes |
| **Accesibilidad** | Disponible para quien corresponde |
| **Confiabilidad** | Fuente segura/oficial |

## 💾 8. Sistema de Información

- 🧑‍💼 **Definición:** conjunto de recursos humanos, tecnológicos, materiales, financieros y metodológicos.
- 🔄 **Función:** capturar, procesar, almacenar y distribuir información para gestión y control.

| Etapa | Acción |
|---|---|
| **Captura** | Recolección de datos |
| **Procesamiento** | Transformación en información útil |
| **Almacenamiento** | Conservación para uso futuro |
| **Distribución** | Entrega a quien necesita decidir |
